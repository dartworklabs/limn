## 맥락

ADR-0027 결정 3은 GET에서 현재 anchor를 메모리로 맞추되 저장하지 않기로 했다. 저장된 핀이 4행·rev 0일 때 원고를 한 줄 밀면 GET은 5행·rev 1을 준다. 유지 실행 전에 다시 한 줄 밀면 다음 GET은 6행·rev 1을 준다. 서로 다른 위치에 같은 rev가 붙는다. 첫 조회의 5행·base_rev 1로 편집하면 POST의 재동기화도 저장된 rev 0에서 1로 올라, 오래된 위치를 받아들이고 엉뚱한 텍스트에 anchor를 저장한다. HTTP 재현에서 기대한 409 대신 200이 나왔으며 실행 자원을 다시 만들어도 재현됐다. GET의 영속 무효과를 유지하면서 저장된 위치와 rev를 한 쌍으로 읽어야 한다.

## 결정

1. 모든 GET은 저장된 핀 위치만 반환한다. `/api/pins`, `/pins.md`, `/api/pins/{id}`, 전체 `/api/meta`, `/api/people`, `/api/overlaps` 등에서 메모리 재동기화를 없앤다. 조회는 계속 아무것도 쓰지 않는다. `rel`·`est`·`state`·`superseded_by`·`suggest_state`·그림 `mark` 같은 기존 계산 필드는 저장 레코드를 바탕으로 지금처럼 계산한다. 클라이언트가 보는 위치·rev는 저장된 쌍이다.
2. 변경 POST는 0.4.48처럼 잠금 아래 재동기화한 핀에 `base_rev`를 대조하고, 재동기화와 허용한 변경을 저장한다. 오래된 편집이 거절되어도 재동기화는 저장한다. 본 뒤 원고가 움직인 클라이언트는 409를 받는다.
3. 시작·60초 유지 실행에 더해 요청과 독립된 검사 루프가 2초마다 파일의 mtime_ns·size·inode만 확인한다(`CHECK_INTERVAL`). 열린 문서에 속한 핀이 가리키는 파일과 문서의 main 파일만 감시한다. 핀 집합 변경을 발견하기 위한 `pins.jsonl` stat도 포함한다. 변화가 없으면 본문을 읽지 않는다. 변화가 있으면 같은 단일 실행 유지 pass를 돌린다. 바뀐 파일만 쓰며 실패하면 원본과 마지막 성공 기준을 유지하고 다음 검사에 재시도한다. 원고 지문은 pass 전에 잡아 실행 중의 새 변경을 놓치지 않는다. 종료 이벤트는 대기를 즉시 깨운다.
4. 원고 수정 뒤 GET의 핀 위치와 HTTP·디스크 `pins.md`는 검사 간격 + 유지 실행 시간만큼 늦을 수 있다. 정상적으로는 몇 초이며 실패하거나 느리면 더 길어진다. 뷰어는 이미 light meta의 `pins_rev`, 즉 `pins.jsonl` 변경 때만 핀을 다시 읽으므로 사람이 보는 변화는 작다. 에이전트는 줄을 고치기 전에 원문을 다시 읽는다.

## Trade-off

- 위치와 rev의 저장 단위를 맞춰 오래된 줄 편집이 잘못 받아들여지는 결함을 없앤다. API 필드·순서·저장 형식은 그대로다.
- 조회의 즉시 줄 맞춤을 포기한다. 2초는 60초 지연을 몇 초로 줄이면서 유휴 때는 작은 파일 집합의 stat만 쓰는 값이다. 느린 파일시스템·실행 실패에는 지연 상한을 보장하지 않는다.
- 별도 저장 파일·프로세스 간 잠금 없이 기존 트랜잭션과 유지 원복을 재사용한다. mtime·크기·inode가 모두 같은 외부 수정은 감지하지 못하며 60초 pass가 보완한다. anchor의 mtime 판정 자체는 바꾸지 않는다.

## 대안

- **메모리 재동기화를 유지하고 미저장 이동이 있는 핀의 편집을 다음 pass까지 거절한다.** 저장 손상은 막지만 현재 화면을 보고 보낸 편집에도 거짓 409가 난다. 기각했다.
- **rev를 영속 예약한다.** 위치마다 rev를 보장할 수 있지만 새 저장 파일과 프로세스 간 잠금이 필요하고 GET 무쓰기 경계와 저장 계약이 복잡해진다. 기각했다.

## 결과

`PinReader`는 저장 전용 읽기 능력으로 남고 재동기화 협력자는 writer에만 둔다. `pins/maintenance.py`와 기동 조립이 변경 검사를 맡는다. 재시작을 포함한 HTTP stale-edit 회귀, 유지 후 정상 편집, GET 무쓰기·저장 위치, 요청 없는 변경 감지, 유휴 무읽기·무실행, 종료와 실패 보존을 검사한다. Handbook·두 SKILL·CHANGELOG를 같은 변경에서 맞춘다. ADR-0027 원문은 동결 상태 그대로 둔다.
