## 맥락

[ADR-0011](0011-figure-documents.md)은 그림 문서의 pick 임계값(D6)을 `cover ≥ 0.6`, `fill ≥ 0.5`로 잠정 확정하고, 지도를 내는 첫 실제 그림 도구로 재어 조정하기로 했다. 그동안 값은 표본 그림 세트로만 쟀다.

2026-10-06에 첫 실제 도구가 생겼다. 논문 개념도 도구(svgkit)가 그림 24장을 한 PDF와 `limn-figure-map/1` 지도로 내보낸다. 요소는 7,855개다.

## 측정

- **대상.** 레이아웃 assert에서 멈추는 두 장(D1·F4)을 뺀 22장, 요소 7,853개 가운데 그림마다 시드를 고정해 고른 3,158개.
- **드래그.** 뷰어 배율 1.42–2.13 px/pt에서 사람이 끄는 상자를 본떴다: 꼭 맞게, 여유를 비율로, 여유를 화면 px로, 일부만, 이웃 둘에 걸쳐. 모서리마다 떨림을 주어 모두 59,492개다.
- **판정.** Limn의 `pick_element`를 그대로 부르고 `COVER_MIN`·`FILL_MIN`만 바꿨다. 격자는 cover 0.30–0.90 × fill 0.20–0.80, 0.05 간격이다.

| 지표 (네 종류 평균) | 0.6 / 0.5 | 0.4 / 0.5 |
| --- | --- | --- |
| 노린 요소를 고름 | 47.4% | 61.4% (+14.0점, 그림 단위 부트스트랩 95% 구간 +11.5~+16.2) |
| 더 얕은 답(다시 끌어야 함) | 20.3% | 12.1% |
| 엉뚱한 요소 | 27.8% | 23.6% |
| 그림 전체 | 3.9% | 1.6% |
| 이웃 둘 → 공통 조상 | 50.0% | 37.5% (둘 중 하나 29.0→40.5%) |

## 결정

**D6을 `cover ≥ 0.4`, `fill ≥ 0.5`로 확정한다.** `fill`은 그대로 두고 `cover`만 내린다.

- 사다리는 위로만 오른다. 너무 깊은 답은 한 단계 올리면 되지만, 너무 얕은 답은 다시 끌어야 한다. 0.4는 다시 끌어야 하는 답을 20.3%에서 12.1%로 줄인다.
- 0.4는 큰 요소를 노린 드래그의 정답률이 가장 높은 지점이다(60.9%). 더 내리면 큰 요소를 감싼 드래그가 안쪽 작은 요소로 새고(0.3에서 55.9%), 이웃 둘 드래그가 공통 조상에 닿는 비율이 무너진다(0.3에서 27.5%).
- cover 0.4에서 fill은 0.2–0.8 어디든 정답률이 0.6점 안에서 같다. 바꿀 근거가 없다.

## 결과

- 나란한 두 요소에 반씩 걸친 드래그는 공통 부모 대신 둘 중 하나를 고르고, 부모는 사다리의 다음 단계가 된다. 공통 조상이거나 둘 중 하나인 비율은 79.0%와 78.0%로 거의 같다.
- 엉뚱한 답의 대부분은 임계값으로 풀리지 않는다. 가는 선·눈금·점은 손으로 끈 상자보다 훨씬 작아 어느 하한에서도 후보가 못 되어, 뒤의 배경이나 부모가 답이 된다. 서로 다른 갈래 사이의 "가장 깊은 것 먼저" 비교도 일부 원인이다. 이는 별도 설계 과제로 남긴다.
- 측정은 그림 도구 하나의 지도 하나와 본뜬 드래그다. 절대값은 비관적일 수 있지만 임계값끼리의 비교에는 쓸 수 있다. 다른 그림 도구가 지도를 내기 시작하면 다시 잰다.
- 근거 문장은 [domain.md](../handbook/domain.md)의 pick 규칙에 둔다.
