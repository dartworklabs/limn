## 맥락

[ADR-0025](0025-html-document-surface.md)로 뷰어가 원문을 직접 그리는 화면이 생겼다. 그러나 일반 텍스트와 소스 코드 파일(그림 스크립트, 참고문헌, 설정, 메모)은 여전히 등록할 수 없다. 사람이 그 줄을 골라 핀을 남길 길이 없다. Markdown 화면은 서버가 센 줄 목록, 쪽 없는 줄 핀, 능력으로 가르는 제안 관문·판정 대상·이력 파일을 이미 갖추었다. 텍스트 문서는 여기서 파싱만 빼면 된다.

이 변경은 에이전트 계약(문서 `kind` 값, `scope` 값, `pins.md` 표시, `/api/source` 필드)과 등록 규칙을 넓히고, 남이 쓴 글을 뷰어의 출처에서 보이는 보안 면(보이지 않거나 글 순서를 바꾸는 문자)을 다룬다. 이 면은 텍스트 문서만의 것이 아니다. 제안 수정의 글은 어느 종류의 문서에서든 그런 문자를 깨끗한 코드에 넣을 수 있다. 그래서 소유자 승인이 필요하다.

## 결정

| # | 결정 | 상태 |
| --- | --- | --- |
| D1 | 문서 종류 `text` 를 더한다. 뷰어가 서버의 줄을 하나씩 고정폭으로 보이고, 파싱하지 않는다. 능력은 Markdown과 같다(`takes_line_pins`·`shows_revisions`·`renders_in_browser`·`takes_suggestions`). 뷰어만 그리는 법을 가른다. `pins.md` 의 문서 절 꼬리말은 `— 텍스트(쪽 없음)` 다 | 승인됨 |
| D2 | `--doc` 경로의 확장자가 닫힌 목록 `TEXT_SUFFIXES` 에 있으면 텍스트 문서다. 대소문자는 가리지 않는다. 목록은 더하기만 한다. 화면이 따로 생길 수 있는 확장자(`.typ`·`.ipynb`)와 흔히 비밀을 담는 확장자(`.env`·`.pem`·`.key`)는 넣지 않는다. 대소문자만 틀린 그림 지도 접미사는 거절한다. 셸과 서버는 같은 목록을 쓰고 시험이 둘을 묶는다 | 승인됨 |
| D3 | 사다리는 고른 줄(`raw`) → 문단(`para`, 빈 줄 사이) → 들여쓰기 블록(새 `scope` 값 `indent`, 핀 `kind` `indent`)이다. 문단과 블록은 짧은 쪽이 먼저다. 둘 이상의 문단에 걸친 선택은 줄로 저장한다 | 승인됨 |
| D4 | 텍스트 문서의 줄 핀은 제안 수정을 받고, 판정 핀의 대상은 그 줄이다. 판정 낱말 파일은 지금 자리 규칙(메인 파일의 `stem` + `.limnverdicts.json`)을 따른다 | 승인됨 |
| D5 | 그린 텍스트는 글자뿐이다. 파서·구문 강조·링크·그림이 없다. 보이지 않거나 글 순서를 바꾸는 문자(숨은 문자)는 코드 포인트로 정한 한 목록이다. Unicode의 `Default_Ignorable_Code_Point`, 탭과 LF를 뺀 C0·C1 제어 문자, U+2028·U+2029, 행간 주석 문자(U+FFF9–U+FFFB)이고, 양방향 제어(`Bidi_Control`)는 앞의 것에 들어 있다. 그 문자가 필요한 정해진 연쇄(이모지의 ZWJ·VS16, 페르시아어·인도계 글자의 ZWJ·ZWNJ, 한자의 이체자 선택자, 파일 맨 앞 BOM 등)만 예외다. 원문 문자는 격리된 span 안에 남긴 채 이름으로 보이고, 문서 머리에 개수를 알린다. 원문이나 제안의 글을 다시 보이는 곳(원문 발췌, 사다리 이름, 제안의 줄 차이)은 문서 종류와 상관없이 같은 목록과 같은 표시를 쓴다. 긴 줄은 늘 접는다 | 승인됨 |
| D6 | 바이트 한도(1 MiB, 서버)와 줄 한도(50,000줄, 뷰어)는 Markdown과 같다. 그리는 요소도 Markdown의 한도(60,000개) 안이다. 줄 하나가 요소 하나, 숨은 문자 하나가 둘이다. 넘으면 이름 보기로 물러선다. 이름 보기는 줄마다 요소 하나이고, 숨은 문자를 `⟨U+200B⟩` 처럼 글자로 보인다. 2,000단위(줄 하나, 숨은 문자 하나)마다, 긴 줄 안에서도 브라우저에 양보하고, 새 그리기가 오면 그 자리에서 멈춘다 | 승인됨 |
| D7 | 제안 수정의 숨은 문자. 제안의 글을 보이는 모든 곳(카드의 줄 차이, 작성 패널과 수정 칸의 409 차이, 넣은 뒤 검토하는 변경 보기의 소스 diff)이 D5의 표시를 쓴다. 편집 칸(`textarea`)은 그 문자를 보이지 못하므로, 칸 아래 한 줄이 초안을 살핀다. 초안이 원문에 없는 숨은 문자를 넣으면 경고색으로 이름과 개수를 말하고, 그 문자가 든 줄을 이름 상자로 보인다. `pins.md` 의 `## 제안 문안` 블록은 그런 제안의 머리 아래에 `숨은 문자: 원문에 없는 U+202E 1개 — … 넣기 전에 그 문자가 필요한지 답글로 묻는다` 한 줄을 더한다. 이 줄은 예외 없이 센다 | 승인됨. `pins.md` 숨은 문자 줄은 승인 질문 뒤 추가(마지막 PoC에서 확인) |
| D8 | 복사는 정규화한다. 한 줄 안의 글은 그대로 복사되고, 줄은 LF로 잇는다. 원래 줄 끝(CRLF, 외톨이 CR, 폼 피드, U+2028 등)은 되살리지 않는다. `/api/source` 는 LF·CRLF가 아닌 줄 끝을 이름별로 센 `line_ends` 를 더 보낸다. 그런 문서에는 문서 머리에 그 개수와 종류를 알린다. Limn의 줄 번호가 LF만 세는 편집기·git과 달라지기 때문이다 | 승인됨. `line_ends` 와 그 알림은 승인 질문 뒤 추가(마지막 PoC에서 확인) |

### D3을 고른 근거

들여쓰기 블록은 언어를 가리지 않고 파이썬 함수, YAML 항목, 함수 호출의 인자 목록, `.bib` 항목을 한 번에 잡는다. 파일 전체 단은 한 핀이 문서 전체를 칠하고 80줄을 넘으면 제안 수정을 둘 수 없다. 문단에는 LaTeX 문서의 `para` 를 그대로 쓴다. 빈 줄로 나뉜 덩어리라는 뜻이 같다.

### D5를 고른 근거

리뷰하는 화면이 원문과 다른 순서로 보이면, 사람은 실제와 다른 코드를 승인한다(Trojan Source, CVE-2021-42574). 보이지 않는 문자는 똑같아 보이는 두 이름을 만들고, 태그 문자는 사람에게 보이지 않는 지시를 에이전트에게 실어 나른다. 원문 문자를 지우면 복사한 글이 원문과 달라진다. 격리 span 안에 남기면 둘 다 피한다. 목록을 Unicode 속성으로 정의하면 빠진 문자를 찾는 기준이 생긴다. 시험이 엔진의 Unicode 표와 모든 코드 포인트를 대조한다. 구문 강조는 번들(멈춤 신호)과 토큰을 DOM으로 짓는 보안 면을 늘리는데, 줄 핀에는 필요 없다.

### D7을 고른 근거

제안 수정의 글은 에이전트가 그대로 넣는다. 카드가 그 글을 날것으로 그리면, 사람은 깨끗해 보이는 줄을 승인하고 에이전트는 다른 뜻의 글을 넣는다. LaTeX·Markdown 제안도 같은 위험이라 표시는 공용 조각 하나(`hidden-chars.js`)에 둔다. `pins.md` 줄은 에이전트에게 보내는 확인 요청이다. 사람의 화면이 경고했어도 에이전트가 따로 알아야, 다른 사람이 쓴 제안이나 태그 문자에 실린 지시를 넣지 않는다. 에이전트가 읽는 형식이 바뀌므로 이 ADR의 계약 변경에 넣는다. 빼는 안은 사람의 화면만 믿는 것이라 기각했다.

## Trade-off

- 코드에 색이 없다. 긴 코드를 읽기는 편집기보다 불편하다.
- 확장자 없는 파일(`Makefile`, `LICENSE`)과 목록에 없는 확장자는 아직 받지 않는다.
- 같은 폴더에서 `stem` 이 같은 두 문서(`plan.md`, `plan.txt`)는 판정 낱말 파일 하나를 함께 쓴다.
- 들여쓰기 블록은 들여쓰기만 본다. 들여쓰기가 어긋난 파일에서는 블록이 기대와 다를 수 있다. 그때도 고른 줄과 문단 단은 맞다.
- 제안 편집 칸(`textarea`)은 숨은 문자를 여전히 브라우저대로 보인다. 칸 아래 줄이 이름과 그 줄을 따로 보여 덮는다.
- `pins.md` 의 숨은 문자 줄은 예외 없이 센다. 이모지의 ZWJ를 넣는 제안도 에이전트가 한 번 묻는다.
- 이름 보기에서 복사하면 숨은 문자 대신 이름이 복사된다. 알림이 그렇게 말한다.
- 복사한 글의 줄 끝은 늘 LF다. CRLF·폼 피드 파일의 원래 줄 끝은 복사로 되살릴 수 없다.
- 옛 서버로 되돌리려면 먼저 텍스트 문서를 인스턴스 설정에서 빼야 한다. 상태 폴더의 핀은 그대로 읽힌다.

## 대안

- **다른 종류가 차지하지 않은 확장자를 모두 텍스트로.** 오타·바이너리·나중의 종류를 삼켜 기각했다.
- **`--doc` 문법에 종류를 적는다.** 등록 문법을 바꿔 기각했다.
- **`text`·`code` 두 종류.** 행동 차이가 없어 기각했다.
- **구문 강조 번들.** 1단계에서는 기각한다. 필요해지면 별도 ADR로 다룬다.
- **긴 줄을 상자 안에서 옆으로 넘긴다.** 휴대폰에서 끌기가 글 고르기와 부딪혀 기각했다.
- **복사할 때 원래 줄 끝을 되살린다.** copy 처리기가 서버의 줄 끝을 다시 넣어야 하고, 같은 줄 번호 문제는 남는다. 기각했다.

## 결과

- 에이전트 계약에 값 셋(문서 `kind` `text`, `scope` `indent`, 핀 `kind` `indent`), `pins.md` 표시 둘(문서 절 꼬리말, `## 제안 문안` 의 숨은 문자 줄), `/api/source` 필드 하나(`line_ends`)가 더해진다. 새 경로는 없다.
- 저장 형식에 새 필드는 없다. 텍스트 핀은 `page` 없는 줄 핀이다.

### 현재 상태 투영

- **영향받는 현재 권위:** `runtime/documents.py` 의 종류·능력·확장자 목록, 등록(`administration/serve_documents.py`, `instance_documents.sh`), `scope` 값(`pins/editing/values.py`), `pins.md`(`pins/listing/render.py`, 숨은 문자 목록 `pins/suggestion.py`), `/api/source`(`documents/source.py`·`http.py`), 뷰어의 텍스트 화면과 숨은 문자 조각(`viewer/js/hidden-chars.js`), 에이전트 계약(`api.md`, SKILL).
- **갱신할 Handbook role/path:** purpose `docs/handbook/purpose.md`(지원 범위), `docs/handbook/domain.md`(능력 표, 사다리, 텍스트 문서), `docs/handbook/viewer.md`(텍스트 화면), `docs/handbook/api.md`(값 목록, 낱말 파일 자리, `/api/source` 의 `line_ends`, `## 제안 문안` 의 숨은 문자 줄), `docs/handbook/instances.md`·`docs/handbook/operations.md`(받는 확장자), `skill/SKILL.md`·`skill/SKILL.ko.md`.
- **효력 형태:** 승인 뒤 한 번에. PoC 브랜치에 시험과 문서를 더한 구현 브랜치 하나가 모두 넣는다.
- **완료 증거:** 계약 스냅숏에 텍스트 문서와 `indent` 가 있다. 직전 릴리스가 텍스트 핀 레코드를 지우지 않는다. 숨은 문자 시험 문서가 원문 순서대로 보이고, 숨은 문자를 넣는 제안이 카드·편집 칸·`pins.md` 에서 드러난다. 두 숨은 문자 목록(뷰어·서버)을 시험이 묶는다. 네 기기군 실측이 있다.
