# 비교 기능 내부 역할 분해

비교 기능의 `core.py`는 이력 조회·원문 diff, 샌드박스 빌드, 비교 작업 캐시를 함께 담고 있다. Git 조회와 공통 결과 타입·범위 판단은 `core.py`, 스냅숏·격리 실행·PDF 빌드는 `execution.py`, 캐시 상태·작업 슬롯·HTTP 요청 결과는 `jobs.py`로 나눈다. 의존 방향은 `jobs → execution → core`이며 `jobs → core` 조회도 허용한다.

동작·한도·저장 순서·오류 종류는 바꾸지 않는다. 테스트의 실패 주입은 실제 호출 모듈에서 계속 작동해야 한다. 분해 후 각 파일에서 쓰지 않는 import와 옛 함수 전달을 제거하고, 응답·상태 파일 차등 비교를 반복한다.
