# 빌드 실행 연결 VSA 이행

빌드 상태·HTTP 요청은 `features/builds/`가 소유하지만 `ServerApplication`은 여전히 빌드 설정 생성·LaTeX 컴파일·추적 빌드·문서 초기 빌드·보기 전용 PDF 감시를 메서드로 감싼다. 이 실행 연결을 `BuildRequests`에 두고 현재 설정·문서·동기화 pull·시계·실패 문구를 호출 시점에 받는다. `server.py`는 기능을 조립하고 시작 과정에서 그 메서드를 호출한다.

문서별 빌드 잠금·상태·기록, view-only PDF의 렌더와 감시, `--git-pull` 순서, 단일 문서의 동기 빌드 실패 기동 거절과 여러 문서의 비동기 시작, 종료 신호의 소유권을 유지한다. 기존 테스트의 실패 주입은 빌드 서비스의 컴파일 경계로 옮기고 응답·빌드 산출물·상태 파일을 기준 커밋과 비교한다.
