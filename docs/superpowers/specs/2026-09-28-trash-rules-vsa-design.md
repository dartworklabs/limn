# 휴지통 조회와 정리의 공통 규칙

핀 목록 기능은 휴지통의 내부 서비스에서 만료 시각·남은 항목·살아 있는 핀과 겹친 사본의 판정을 가져온다. 같은 규칙을 휴지통 쓰기와 목록 읽기가 모두 쓰므로 순수 핀 도메인 `pins/trash.py`가 소유하도록 옮긴다. 목록과 휴지통은 이 모듈을 직접 부르고 이전 서비스의 전달 별칭은 지운다.

만료 경계, 날짜 해석 실패 처리, 저장 순서, HTTP 응답과 휴지통 파일 바이트를 유지한다. 기준 커밋과 변경본을 별도 프로세스로 비교하며, 변조 검출과 해당 테스트 및 전체 게이트를 확인한다. Handbook에 공통 규칙의 위치를 반영한다.
