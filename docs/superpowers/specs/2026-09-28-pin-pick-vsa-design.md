# PDF 선택 VSA 이행

`POST /api/pick`의 입력 검사, 위치 해석, 200 응답을 `features/pins/location/`이 소유한다. 공통 요청 가드와 문서 선택은 기존 처리기에 둔다. SyncTeX·텍스트 역변환과 토큰 캐시는 위치 기능으로 옮기고, 여러 핀 경로가 함께 쓰는 저장 핀의 파일 위치·anchor 규칙만 `locate.py`에 둔다.

수락 기준은 입력 거절 순서, 사라진 빌드의 200 응답, 줄 위치·보기 전용 영역·네 가지 거절 응답의 상태·본문·필드 순서가 같고, 다른 요청과 상태 파일이 영향을 받지 않는 것이다. 테스트는 직접 파서·응답 검사와 실제 HTTP 경로, 기준 커밋과의 별도 프로세스 차등 비교를 사용한다. 변경 뒤 `server.py`와 평면 `App`에서 `pick` 전달 메서드를 제거한다.
