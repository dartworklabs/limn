# 인스턴스 업데이트 명령 분리

`instances.sh`는 모든 인스턴스 명령의 공통 셸 환경과 `limn update`의 태그 조회·설치·재시작을 함께 담는다. 설치·되돌리기 절차는 업데이트 명령만 바뀔 때 수정되므로 `features/administration/instance_update.sh`가 소유한다. `instances.sh`는 공통 설정·도구, 명령 선택, timeout과 유닛·상태 조회 협력자를 제공하고 이 기능 파일을 같은 패키지 경로에서 불러온다. 업데이트의 판단·출력·부수효과는 한 파일에서 찾는다.

`--ref`·`--from`·`--force`·`--no-restart`·`--dry-run`, 태그 실패와 최신 판의 무작업, uv 설치·유닛 재시작·준비 대기·되돌리기 문구를 그대로 유지한다. 상태 폴더를 건드리지 않고, 설치된 패키지의 `limn` 명령도 기능 파일을 찾는다. 실행할 인스턴스의 설정과 포트·상태를 읽는 기존 공통 함수·전역 값은 이 분리에서 바꾸지 않는다.

기존 셸 인스턴스 테스트로 허용·거절·상태 변화를 확인하고, 패키지 wheel에 새 파일이 포함되는지 검사한다. ShellCheck와 전체 게이트를 거친 뒤 Handbook의 실행 코드 소유권을 갱신한다.
