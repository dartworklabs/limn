# 비교 구현의 기능 소유권 이행

Git 이력, diff, 비교 PDF 빌드·캐시의 구현이 현재 단일 `limn/revisions.py`에 있다. 우선 이 구현을 `features/revisions/core.py`로 옮기고 모든 생산 코드와 테스트가 새 단일 모듈을 가리키게 한다. 함수·상태·파일 형식과 실행 순서는 그대로 둔다. 이 단계는 내부 역할 분해의 출발점이며, 옛 모듈은 남기지 않는다.

이후 Git 읽기·스냅숏·샌드박스·캐시 작업의 의존 방향을 확인해 파일을 나눈다. 비교 작업을 테스트가 패치하는 지점은 실제 호출 경계에 맞춰 옮기고, 실패 주입 결과를 보존한다.
