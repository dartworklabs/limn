# 빌드 읽기 경로 VSA 이행

`GET /api/build`, `/pdf`, `/pages/<name>`의 쿼리 검사, 빌드 상태 응답, PDF·쪽 파일 선택과 거절을 `features/builds/`가 소유한다. 처리기는 공통 요청 가드와 바이트 전송만 담당한다. 빌드 실행·이력·쪽 선택의 공통 계산은 아직 `build.py`에 두며, 빌드 쓰기 경로를 옮길 때 함께 경계를 정리한다.

빌드 상태 로그 다이어트는 재빌드 응답도 공유하므로 현재 `web.answers` 규칙을 호출한다. 경로·상태 코드·헤더·본문과 파일 부재의 fallback 순서는 바꾸지 않는다. 기준 커밋과의 별도 프로세스 차등 비교와 기존 HTTP 계약 테스트로 확인하고, 조립 지점의 세 정적 전달 항목을 제거한다.
