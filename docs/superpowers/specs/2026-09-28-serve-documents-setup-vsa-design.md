# 서버 기동 문서 선택 규칙 분리 설계

> **상태: 확정.** [백엔드 VSA 점진 이행 설계](2026-09-28-backend-vsa-migration-design.md)와 ADR-0009의 운영 기능 정리 단계다.

## 대상

`startup.py`는 접근 옵션·포트·문서 해석·상태 폴더·화면 이름·기동 요약을 함께 담는다. 문서 인자(`--doc`, `--main`)의 타입과 거절·문서 구성·기본 원고 파일 찾기는 하나의 변경 이유를 가지며 현재 파일의 큰 부분을 차지한다.

## 선택

이 문서 선택 규칙을 `features/administration/serve_documents.py`로 옮긴다. `server.configure_run()`이 명시적으로 이를 호출하고, 테스트도 새 소유자를 직접 확인한다. 공통 `StartupRefused` 값은 다른 기동 단계도 쓰므로 `startup.py`에 둔다. 문서 선택 모듈은 `server.py`를 가져오지 않고 명시적 인자만 읽는다. 권한·포트·상태 폴더 규칙과 선택·거절 순서는 유지한다.

## 합격 기준

- 문서 인자 해석·선택의 권위가 새 모듈 하나이고 옛 `startup.py`에 전달 함수가 남지 않는다.
- 문서별 결과·거절 문장과 실행별 문서 조립이 기준 커밋과 같다.
- 전체 테스트, 셸·정적·Handbook 검사가 통과한다.
