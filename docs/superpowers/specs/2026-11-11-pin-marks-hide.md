# 쪽 위의 핀 표시 숨기기

> **상태: 승인 대기.** 소유자가 2026-11-11에 문제를 말하고("그림에 핀이 꽂혀있는 경우 색 때문에 잠깐 핀을 안보이게 하는 상태에서 어떻게 고쳐졌나 확인하고 싶을 때가 있어. 현재 핀을 숨기기가 어려워"), 진단과 후보를 본 뒤 범위와 선택을 위임했다. 화면 변경이므로 네 기기군 PoC를 보인 뒤에 머지한다.

## 문제

핀의 마크는 그 핀이 가리키는 것 위에 놓인다. PDF 쪽에서는 상태색 2px 테두리와 8% 바탕, 번호 배지다. 검토 대기 핀의 마크는 고친 곳을 그 자리에서 보라고 남겨 두는데, 고친 것이 그림의 색이면 그 마크가 결과를 가린다. 밝은 테마에서 검토 대기 마크 아래의 흰 면은 `#f3eefc`로, 옅은 노랑 `#fff3b0`은 `#f3e3b3`으로 보인다.

마크를 끄는 조작은 없다. 마크 없이 보려면 [확인]으로 판정부터 하거나(되돌리기 6초), 변경 보기의 겹쳐 보기로 화면을 바꾸거나(배율과 자리가 달라진다), PDF를 내려받아야 한다.

## 요구사항

1. **켜고 끄기.** 키 `H`를 짧게 누르면 쪽 위의 핀 표시가 모두 꺼지고, 다시 누르면 켜진다. 입력 칸 안, 열린 대화상자 아래, 변경 보기에서는 받지 않는다. 한글 자판에서는 물리적 `H` 키다.
2. **잠깐 보기.** `H`를 350ms 넘게 누르고 있으면 누르는 동안만 바뀌고, 떼면 누르기 전으로 돌아간다. 표시는 키를 누르는 순간 바뀐다.
3. **터치.** [더보기]에 `핀 표시` 스위치를 둔다. 누르면 시트가 닫히고 쪽이 보인다.
4. **꺼진 동안의 알림.** 상태 줄에 `핀 표시를 숨겼습니다 [다시 보이기]`가 남는다. 잠깐 보기는 상태 줄에 쓰지 않는다.
5. **숨는 범위.** PDF 쪽의 마크와 배지, Markdown·텍스트 문서의 줄 바탕·그림 테두리·배지다. 핀, 카드, 쪽 판정 줄, 선택 상자, 고르는 중인 줄의 색은 그대로다. 숨은 배지는 Tab과 화면 낭독기에서 빠진다.
6. **저절로 켜짐.** 카드의 [보기]가 그 핀의 표시로 갈 때, 핀 저장·덧붙이기의 되돌리기 칩이 제 마크 위에 설 때 표시를 다시 켠다.
7. **기억하지 않음.** 꺼짐은 그 화면의 상태다. 다시 읽으면 모두 보인다.
8. **그림 문서의 마크는 바탕을 칠하지 않는다.** 테두리와 배지만 그린다. LaTeX 문서와 보기 전용 PDF의 마크는 그대로다.

## 비범위

- 서버, HTTP API, `pins.md`, 저장 형식. 아무것도 보내지 않는다.
- 핀 하나만 숨기기. 전체를 끄는 조작으로 충분한지 먼저 본다.
- 원고 보기에서 직전 빌드 그림을 제자리에 겹쳐 보기, 핀을 찍은 시점의 그림 보존. 뒤의 것은 빌드 보존 정책이 바뀌므로 따로 설계한다.
- 터치의 길게 누르기로 잠깐 보기. 길게 누르기는 이미 선택을 시작하는 제스처다.

## 고른 것과 이유

- **한 키에 두 뜻(짧게: 바꾸기, 길게: 잠깐).** "잠깐 안 보이게"는 상태가 남지 않는 쪽이 맞고, 여러 쪽을 넘기며 볼 때는 꺼 두는 쪽이 맞다. 키를 둘로 나누면 외울 것이 늘어난다.
- **`H`.** 글자 키 가운데 쓰이는 것이 없고(숫자는 판정, `?`는 도움말), hide의 머리글자다.
- **그림 문서만 바탕 제거.** 그림 문서의 쪽은 전부 그림이라 바탕이 늘 판단을 방해한다. LaTeX 쪽은 대부분 글이고, 글 위에서는 바탕이 영역을 알아보게 한다. 그 아래가 그림인지는 뷰어가 알 수 없으므로, 그런 쪽은 숨겨서 본다.
- **스위치는 [더보기]에.** 도구 줄에는 자리가 없다(320px에서 이미 칩이 줄어든다). 터치에서는 두 번 눌러야 닿지만, 다시 켜는 길은 상태 줄에 한 번 누름으로 있다.

## 시험

- 순수 규칙: 자판별 키(`marksKey`), 누른 길이(`marksAfterPress`).
- 실제 뷰어: 끄고 켜기와 서버 기록 불변, 잠깐 보기(켜진 때·꺼진 때), 창이 키를 잃을 때, 입력 칸과 대화상자, [다시 보이기], [보기], 되돌리기 칩, 휴대폰의 스위치, 영어 문구, Markdown 문서의 줄 바탕과 배지, 그림 문서 마크의 바탕.
