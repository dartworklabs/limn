# 인스턴스 생명주기와 조회 명령의 소유권

`instances.sh`에는 설정·포트·유닛·테일넷·토큰 파일을 다루는 공통 함수와 모든 CLI 명령이 함께 있다. 사용자 동작의 입구를 `features/administration/instance_lifecycle.sh`(`run`·`add`·`start`·`stop`·`remove`)와 `instance_inspection.sh`(`list`·`status`·`url`·`snippet`)로 나눈다. 두 파일은 기존 공통 함수와 문서 검사 함수를 호출하고, `instances.sh`는 환경 초기화·공통 도구·명령 선택을 소유한다. `add`가 출력하는 조각은 조회 기능의 `cmd_snippet`을 부른다.

동작과 출력은 그대로다. `add`의 설정 파일 안전 검사, 같은 상태 폴더·포트 충돌, 문서 자동 탐지, 잠금 해제 뒤 기동 대기, 프록시 노출 제한과 토큰 파일 환경 변수는 특히 유지한다. `remove`는 상태 폴더를 지우지 않는다. 조회는 저장 파일을 바꾸지 않는다. 기존 설정의 키·바이트·명령 인자·실행 권한은 바꾸지 않는다.

코드 본문을 기준 커밋과 비교하고, 기존 셸 테스트의 정상·거절·출력·설정 바이트, wheel 파일 포함, ShellCheck, 전체 회귀를 확인한다. 함수 본문은 먼저 그대로 옮겨 동작과 소유권을 분리하고, 큰 함수의 내부 단계 개선은 별도 검증 가능한 변경에서 한다.
