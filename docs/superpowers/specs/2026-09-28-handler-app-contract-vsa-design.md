# 공통 처리기 앱 계약 축소 설계

> **상태: 확정.** [백엔드 VSA 점진 이행 설계](2026-09-28-backend-vsa-migration-design.md)와 ADR-0009의 조립 지점 정리 단계다.

## 대상과 선택

`web/app.py`의 `App` 프로토콜은 기능별 서비스·편집 보조 함수·조회 함수를 포함하지만 현재 처리기는 등록 경로와 공통 가드·문서 선택에 필요한 값만 직접 읽는다. 각 기능은 자기 `http.py`·`routes.py`의 좁은 계약을 이미 갖는다.

`App`에는 처리기가 실제로 참조하는 실행 설정의 Origin 검사 값, 접근 가드, 문서 선택, 사람 기록과 거절 첫 화면 메시지, GET·POST 경로 등록 목록만 남긴다. 기능별 계약은 기능 패키지에 둔다. `ServerApplication`의 실행별 자원·공개 메서드·HTTP 응답은 이번 변경에서 건드리지 않는다. 이후 별도 단계에서 조립 지점의 기능별 전달 표면을 줄인다.

## 합격 기준

- `App`이 처리기의 직접 의존성만 선언하고 기능 서비스 타입을 가져오지 않는다.
- `ServerApplication`의 타입 계약, 관련 HTTP 테스트와 정적 검사가 통과한다.
- 실행 동작과 외부 계약은 바뀌지 않는다.
