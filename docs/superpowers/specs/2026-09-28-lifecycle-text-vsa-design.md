# 핀 생명주기 본문 검사의 소유권

답글과 다시 열기 사유에만 쓰는 `parse_thread_text`와 길이 상한을 공통 `web/parse.py`에서 `features/pins/lifecycle/input.py`로 옮긴다. 기존 호출자는 생명주기 입력을 직접 쓰고 공통 파서에 전달 별칭은 남기지 않는다. 멘션처럼 여러 기능이 함께 쓰는 파서는 공통에 둔다.

줄바꿈·제어 문자 정리, 빈 값, 길이 상한, 거절 문장·reason, 요청 필드 순서, 저장 바이트를 유지한다. 기준 커밋과 변경본의 실제 HTTP·상태 파일을 별도 프로세스로 비교하고, 검사 문구를 바꾼 복사본에서 비교기가 차이를 검출하는지 확인한다. Handbook의 소유권 지도를 갱신한다.
