# 토큰 상태 쓰기의 관리 기능 소유

`limn token`의 생성·취소는 현재 공통 접근 제어 모듈 `access.py`에 있고, 관리 명령은 다시 그 함수를 호출한다. 토큰 발급·취소는 관리 기능의 사용자 동작이므로 `features/administration/token_state.py`가 잠금 아래 읽기·쓰기·감사 순서를 소유한다. 요청 인증에 쓰는 토큰 파일 읽기, 해시, 일정 시간 비교와 Bearer 파싱은 여러 입구의 공통 보안 경계인 `access.py`에 남긴다. 이전 함수를 전달용 별칭으로 남기지 않는다.

명령의 인자·출력·종료 코드, 기본 이름과 충돌 처리, 저장 파일의 바이트·`0600` 권한, 잠금 이름, 감사의 시점과 비밀 제외, 저장 토큰 파일 실패 시 취소 순서를 그대로 유지한다. 잘못된 이름과 읽을 수 없는 파일에서는 쓰지 않는다. 실행 중인 서버는 다음 요청부터 새 토큰을 받고 취소한 토큰을 거절한다. 인증·권한 정책이나 저장 형식은 바꾸지 않는다.

기준 커밋과 변경본을 별도 프로세스에서 같은 시계·난수로 실행해 명령 출력과 상태 파일 바이트·권한을 비교한다. 비교기가 감사 값이나 파일 권한 변경을 검출하는지도 확인한다. 관련 단위·CLI·보안 테스트와 전체 게이트를 돌린 뒤 Handbook의 현재 소유권을 갱신한다.
