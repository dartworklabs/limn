# 멤버 상태 쓰기의 관리 기능 소유

`limn member`의 파일 읽기·추가·삭제·역할 변경이 공통 접근 제어 모듈 `access.py`에 남아 있다. 이 명령의 상태 입구를 `features/administration/member_state.py`로 옮긴다. 서버의 요청 신원·입장·역할 판단과 `people.json` 역할 해석은 공통 `access.py`가 계속 소유한다. `people.json`의 레코드 검사와 저장 형식은 `people.py` 한 곳에서 공유한다. 옛 멤버 함수의 전달 별칭은 남기지 않는다.

CLI 입력의 유효성, 기본 이름·역할, 없는 멤버와 같은 역할, 손상된 파일의 거절, 파일 잠금·원자적 `0600` 쓰기·감사의 순서와 내용은 유지한다. 감사 싱크 타입은 관리 기능의 대상·감사 모듈이 소유한다. 이 변경은 역할 권한이나 파일 형식을 바꾸지 않는다.

기준 커밋과 변경본을 별도 프로세스에서 같은 시계·난수로 실행해 명령 출력과 상태 파일 바이트·권한을 비교한다. 비교기가 멤버 감사 값 또는 저장 권한 변경을 검출하는지도 확인한다. 관련 보안·CLI 테스트와 전체 게이트를 돌리고 Handbook의 현재 소유권을 갱신한다.
