# 재빌드 요청 VSA 이행

`POST /api/rebuild`의 `log`·`async` 스위치, 응답 형식·로그 다이어트, 동기·비동기 실행 선택을 `features/builds/`가 소유한다. 처리기는 공통 권한·문서 선택·본문 검사와 전송을 유지한다. 실행 중 잠금과 상태 갱신은 기존 `build.py`의 함수가 담당하며, 원고 복사·컴파일·쪽 게시의 동작은 바꾸지 않는다.

조립 지점은 문서별 빌드 한 번을 수행하는 함수와 현재 시각을 빌드 서비스에 연결한다. 시작 절차와 PDF 변경 감시도 같은 서비스의 동기·비동기 실행을 호출한다. HTTP 상태·키 순서·로그 내용과 빌드 파일·상태를 기준 커밋과 비교한다.
