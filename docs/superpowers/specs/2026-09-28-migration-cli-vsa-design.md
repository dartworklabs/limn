# 이전 명령 관리 슬라이스 설계

> **상태: 확정.** [백엔드 VSA 점진 이행 설계](2026-09-28-backend-vsa-migration-design.md)와 ADR-0009의 운영 CLI 단계다.

## 대상과 선택

`limn migrate`는 이전 설치의 설정과 상태 디렉터리를 옮기는 하나의 운영 동작이지만 구현 파일이 최상위 `migrate.py`에 있다. 이를 `features/administration/migrate.py`로 옮기고 `cli.py`가 해당 기능을 호출한다. 명령 출력, 종료 코드, 기존 파일 보존, `--dry-run`과 `--move-state`의 검사를 그대로 둔다.

한 함수 안에 섞인 인자 구성, 대상 선택, 설정 복사, 상태 이동, 결과 안내는 같은 기능 파일의 작은 단계 함수로 분리한다. 각 단계는 기존 순서대로 실행하며 예외와 파일 쓰기 순서가 달라지지 않도록 별도 프로세스에서 기존 명령과 비교한다.

## 합격 기준

- 최상위 `migrate.py`가 사라지고 운영 기능이 명령을 소유한다.
- 성공·거절·반복·dry-run·상태 이동의 stdout/stderr, 종료 코드와 파일 바이트가 같다.
- 전체 테스트와 셸·정적·Handbook 게이트가 통과한다.
