# 핀 편집 필드 검사 VSA 시공 계획

1. 네 필드 파서의 생산 코드·테스트 소비자와 기존 HTTP 차등 시나리오를 확인한다.
2. `fields.py`로 검사와 필요한 타입·상수를 옮기고 `editing/input.py`·`editing/location.py`를 연결한다. `web/parse.py`의 이전 함수·불필요한 import를 지운다.
3. 직접 파서 테스트의 호출 위치를 바꾸고 핀 추가·편집의 정상·거절·저장 결과를 기준 커밋과 비교한다. 비교기 변조 검출을 확인한다.
4. Handbook 구조·코딩 예와 파일 지도를 갱신하고 전체 pytest·셸·정적·출판 검사를 실행한 뒤 독립 커밋으로 묶는다.
