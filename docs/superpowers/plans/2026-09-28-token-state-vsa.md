# 토큰 상태 쓰기 VSA 시공 계획

1. 변경 전 소스를 별도 디렉터리에 보관하고 고정 시계·난수의 CLI 차등 시나리오를 실행한다.
2. 토큰 생성·취소·쓰기·시각·이름 규칙을 `features/administration/token_state.py`로 옮긴다. 인증 읽기·해시·Bearer·역할 규칙은 `access.py`에 둔다.
3. 관리 명령과 해당 테스트의 호출·실패 주입을 새 소유자로 연결한다. 옛 진입점은 삭제한다.
4. 토큰 생성·취소·중복·오류·감사·저장 실패의 집중 테스트와 별도 프로세스 차등 비교를 실행한다. 비교기 변조 검출을 확인한다.
5. Handbook 구조·파일 지도를 고치고 전체 pytest, 셸 테스트, Ruff, mypy, shellcheck, Handbook 출판 검사를 실행한 뒤 독립 커밋으로 묶는다.
