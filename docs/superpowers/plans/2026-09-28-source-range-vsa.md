# 원문 구간 조회 VSA 시공 계획

1. `SourceRange`를 위치 기능의 순수 `range.py`에 두고 두 경로의 입력 검사를 `input.py`로 옮긴다.
2. `locate.py`의 구간 조회 함수를 위치 기능의 `range.py`로 옮기고 실행별 위치 서비스가 설정과 겹침 조회를 제공한다.
3. 기능 HTTP 입구가 두 GET 경로를 답하게 하고 앱의 두 전달 메서드를 지운다. 기존 실패 주입 테스트를 새 경계에 맞춘다.
4. 별도 프로세스 차등 비교, 관련 테스트와 전체 검수 게이트, Handbook 현재 구조 갱신을 마친다.
