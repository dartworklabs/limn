# 관리 CLI VSA 시공 계획

1. 인스턴스 대상·감사 협력자를 `targets.py`, 토큰 파일 정책과 입출력을 `token_files.py`로 옮긴다.
2. `token`·`member`의 명령 파싱·응답을 각 `tokens.py`·`members.py`로 옮기고 `cli.py`는 명령을 선택해 호출한다.
3. 내부 함수에 붙은 테스트의 실패 주입 위치를 새 소유자로 옮기고 명령 출력·상태 파일을 기준 커밋과 별도 프로세스에서 비교한다.
4. 집중 테스트·전체 게이트·패키지 스모크를 실행하고 Handbook 파일 지도를 갱신한다.
