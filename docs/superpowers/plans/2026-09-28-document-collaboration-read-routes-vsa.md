# 문서·사람 조회 경로 VSA 시공 계획

1. 기준 커밋과 같은 경로·시계·파일 시각을 가진 원고에서 네 GET 경로의 허용·거절 응답과 상태 파일을 별도 프로세스로 기록한다.
2. `GetRequest`를 공통 등록 함수의 인자로 만들고 이미 등록된 빌드·이력 경로를 연결한다.
3. 문서·사람 기능의 `routes.py`를 추가하고 실행별 서비스를 등록한 뒤 공통 처리기의 옛 네 분기를 지운다.
4. 관련 테스트와 별도 프로세스 차등 비교, 응답 변이 검사를 통과시킨다.
5. 전체 pytest, 셸 테스트, Ruff, ShellCheck, mypy, Handbook 출판 검사를 통과시키고 현재 구조 문서를 맞춰 독립 커밋으로 묶는다.
