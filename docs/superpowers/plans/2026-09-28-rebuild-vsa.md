# 재빌드 요청 VSA 시공 계획

1. 재빌드 쿼리 스위치를 빌드 기능의 `input.py`로 옮긴다.
2. 빌드 상태와 재빌드 응답 규칙을 `answer.py`로 모으고, `http.py`가 서비스를 호출한다.
3. 동기·비동기 실행과 보기 전용 거절을 `service.py`로 옮긴다. 조립 지점은 실행별 협력자만 연결한다.
4. 처리기·`App` 계약과 시작·감시 호출을 새 서비스에 연결하고 오래된 전달 메서드를 제거한다.
5. 기준 커밋과 HTTP·파일 상태를 차등 비교하고, 기존 빌드 테스트·전체 게이트를 통과시킨 뒤 Handbook을 동기화한다.
