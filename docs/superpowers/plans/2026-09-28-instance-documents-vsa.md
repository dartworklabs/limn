# 인스턴스 문서 명령 VSA 시공 계획

1. 문서 검사·자동 탐지·`doc` 명령의 함수와 `add`·상태 조회의 실제 호출을 확인한다. `stat_fmt`·`detect_main`은 여러 소비자의 공통 도구로 남긴다.
2. 문서 상수와 세 함수 묶음을 `instance_documents.sh`로 옮기고 기존 정의를 삭제한다. 인스턴스 관리자는 명령 실행 전에 기능 파일을 불러온다.
3. 셸 인스턴스 테스트, 기준 본문 비교와 wheel 파일 확인으로 출력·파일·거절 경로를 검증한다.
4. Handbook과 CI의 파일·정적·설치 게이트를 갱신하고 전체 검사를 실행한 뒤 독립 커밋으로 묶는다.
