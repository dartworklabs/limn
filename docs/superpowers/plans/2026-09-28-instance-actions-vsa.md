# 인스턴스 명령 VSA 시공 계획

1. 명령별 함수의 실제 호출과 공통 협력자를 확인한다. 공통 환경·잠금·파일·포트·유닛·네트워크 도구는 `instances.sh`에 둔다.
2. 생명주기 명령을 `instance_lifecycle.sh`, 조회 명령을 `instance_inspection.sh`로 옮기고 이전 정의를 삭제한다. 명령 실행 전에 두 파일을 패키지 상대 경로에서 불러온다.
3. 기준 커밋과 옮긴 함수 본문을 비교하고 셸 테스트 190건, wheel 포함과 설치 스모크를 확인한다.
4. Handbook과 CI의 현재 파일·검증 목록을 갱신하고 전체 pytest·정적·문서 검사를 거쳐 독립 커밋으로 묶는다.
