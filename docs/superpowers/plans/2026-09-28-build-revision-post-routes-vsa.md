# 빌드·이력 POST 경로 VSA 시공 계획

1. 기준 커밋 별도 프로세스에서 두 POST 경로의 성공·거절·문서 오류·알 수 없는 경로를 기록한다. 빌드 실행과 비교 작업은 고정된 결과로 주입한다.
2. 공통 POST 문서 경로 계약을 만들고 각 기능 `routes.py`에 자기 경로 이름·응답 함수를 둔다.
3. 실행별 조립 지점에서 두 함수를 등록하고 처리기의 옛 경로 목록·분기를 지운다.
4. 관련 테스트와 별도 프로세스 차등 비교, 응답 변이 검사를 통과시킨다.
5. 전체 pytest, 셸 테스트, Ruff, ShellCheck, mypy, Handbook 출판 검사를 통과시키고 현재 구조 문서를 맞춰 독립 커밋으로 묶는다.
