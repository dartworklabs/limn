# 빌드 읽기 경로 VSA 시공 계획

1. 기준 커밋의 세 GET 경로와 빠진 쪽 이미지·PDF 거절 응답을 별도 프로세스에서 기록한다.
2. 공통 `Reply`와 JSON 직렬화를 `web/reply.py`로 옮긴다. 빌드 경로 매칭·응답을 `features/builds/routes.py`에 둔다.
3. 조립 지점이 GET 경로를 등록하고 처리기가 등록 순서대로 호출한다. 기존 세 분기를 제거한다. 경로 목록 테스트가 등록된 경로도 검사하도록 바꾼다.
4. 해당 테스트와 별도 프로세스 차등 비교를 실행하고, 일부러 바꾼 응답을 비교가 잡는지 확인한다.
5. 전체 pytest, 인스턴스 셸 테스트, Ruff, ShellCheck, mypy, Handbook 출판 검사를 통과시킨 뒤 현재 구조 문서를 동기화하고 독립 커밋으로 묶는다.
