- [ ] Step 1: History files by capability, not a shared pathspec. The LaTeX extension pathspec (`revisions/core.py:424-426`) stays as it is and gains no `md`; a Markdown document's history is its own `.md` file alone, passed through the file-list path figure documents use (`revision_scope` with `files`, `_files_scope`, `revisions/core.py:403-408`, `:430-448`). `history_files` (`builds/queries.py:273-286`) chooses by capability: element map -> map, PDF and scripts; `renders_in_browser` -> `(doc.main,)`; otherwise `None` (the LaTeX path).
