# 멤버 상태 쓰기 VSA 시공 계획

1. 기준 소스와 CLI 차등 시나리오를 보관하고 사람 파일의 정상·손상·없는 경우를 확인한다.
2. 멤버 파일 읽기·잠금 아래 갱신·추가·삭제·역할 변경을 `member_state.py`로 옮긴다. 공통 역할 해석은 `access.py`에, 저장 형식은 `people.py`에 둔다.
3. 감사 싱크 타입을 관리 대상 모듈로 옮기고 토큰·멤버 상태 쓰기가 그 타입을 받게 한다. 명령과 해당 테스트를 새 소유자에 직접 연결하고 옛 함수를 삭제한다.
4. 집중 테스트, 별도 프로세스 차등 비교와 비교기 변조 검출을 실행한다. Handbook 구조·파일 지도를 고친다.
5. 전체 pytest, 셸 테스트, Ruff, mypy, shellcheck, Handbook 출판 검사를 실행한 뒤 독립 커밋으로 묶는다.
