# 인스턴스 업데이트 명령 VSA 시공 계획

1. `latest_tag`·`cmd_update`의 호출과 공통 협력자를 확인하고 `instances.sh`의 나머지 명령과 분리한다.
2. 두 함수를 `features/administration/instance_update.sh`로 옮기고 명령 실행 전 패키지 상대 경로에서 불러온다. 이전 함수 정의는 삭제한다.
3. 기존 190개 셸 인스턴스 테스트로 업데이트의 정상·거절·되돌리기 출력을 확인하고, 빌드한 wheel에 스크립트가 있는지 검사한다.
4. Handbook의 파일 지도와 인스턴스 명령의 현재 정본을 갱신한다. 전체 pytest·정적 검사·문서 출판 검사를 실행하고 별도 커밋으로 묶는다.
