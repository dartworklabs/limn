# 핀 조회 경로 VSA 시공 계획

1. 기준 커밋과 변경을 별도 프로세스에서 목록·`pins.md`·원문·겹침의 성공·거절 경로로 비교한다. 시계·원고 mtime·임시 경로를 고정한다.
2. 목록과 위치 기능에 각 GET 경로 함수를 만들고 실행별 조회·정리·주소 협력자를 등록한다.
3. 공통 처리기의 여섯 경로 분기를 제거하고 경로 목록 검사가 새 기능 소스도 보도록 고친다.
4. 관련 테스트와 차등 비교, 응답 변이 검사를 실행한다.
5. 전체 pytest, 셸 테스트, Ruff, ShellCheck, mypy, Handbook 출판 검사를 통과시키고 현재 구조 문서를 맞춰 독립 커밋으로 묶는다.
