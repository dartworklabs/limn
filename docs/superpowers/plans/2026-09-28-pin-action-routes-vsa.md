# 핀 ID 동작·전체 비우기 POST 경로 VSA 시공 계획

1. 기준 커밋과 변경을 별도 프로세스에서 수명 주기·처리 중 표시·편집·휴지통 흐름으로 비교한다. 시계·원고 mtime·임시 경로를 고정한다.
2. 공통 핀 ID·기타 POST 요청 계약을 만들고 각 기능 `routes.py`에 자기 동작·전체 비우기 이름과 응답 함수를 둔다.
3. 조립 지점에서 중복 없이 등록하고 공통 처리기를 경로 모양·등록 조회·전송만 하는 코드로 바꾼다.
4. 관련 테스트, 별도 프로세스 차등 비교와 변이 검사를 통과시킨다.
5. 전체 pytest, 셸 테스트, Ruff, ShellCheck, mypy, Handbook 출판 검사를 통과시키고 현재 구조 문서를 맞춰 독립 커밋으로 묶는다.
