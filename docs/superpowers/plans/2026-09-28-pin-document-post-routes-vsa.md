# PDF 선택·핀 만들기 POST 경로 VSA 시공 계획

1. 기준 커밋의 PDF 선택·핀 만들기·기존 문서 POST 응답과 상태 파일을 고정 입력으로 별도 프로세스에서 기록한다.
2. `PostDocRequest`와 등록 정보의 `new_pin`을 추가하고 네 기존/신규 등록 함수에 연결한다.
3. 위치·편집 기능에 각 POST 경로 함수를 두고 공통 처리기의 두 분기를 삭제한다.
4. 관련 테스트·별도 프로세스 차등 비교·응답 변이 검사를 통과시킨다.
5. 전체 pytest, 셸 테스트, Ruff, ShellCheck, mypy, Handbook 출판 검사를 통과시키고 현재 구조 문서를 맞춰 독립 커밋으로 묶는다.
