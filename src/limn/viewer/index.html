__LIMN_MARK__Limn — 사용법

  
한 바퀴

  
    
    
  1. PDF 위에서 고칠 곳을 드래그합니다. 점선 상자('새 핀')가 남습니다.
    2. 
    
  2. 사이드바의 범위 단계(드래그한 줄 / 문단 / 환경)와 한 줄 버튼(위·아래 +/−)으로 줄 범위를 맞춥니다.
    3. 
    
  3. 메모를 쓰고 핀 저장(⌘ Enter / Ctrl+Enter). 알림의 [되돌리기]로 바로 취소할 수 있습니다.
    4. 
    
  4. 에이전트에게 "핀 처리해줘"라고 말합니다. 에이전트는 pins.md 한 장을 읽고 원고를 고친 뒤 핀을 닫습니다.
    5. 
    
  5. PDF 재빌드로 결과를 봅니다. 보던 쪽과 쓰던 메모는 그대로 남습니다.
    6. 
    
  6. 결과가 맞으면 [확인], 틀렸으면 [답글]에 무엇이 틀렸는지 적습니다. 보내면 핀이 다시 열려 에이전트에게 갑니다.
    7. 
  

  
휴대폰·태블릿(터치)

  
길게 누르기PDF 위를 길게 누르면 그 자리 문단을 고릅니다. 스크롤·확대는 평소처럼 됩니다

    
선택켜면 한 손가락으로 끌어 영역을 고르고, 탭하면 그 자리 문단을 고릅니다. 두 손가락으로 벌리면 PDF 만 커집니다. 핀을 저장하거나 취소하면 저절로 꺼집니다

    
핀 N핀 목록 패널(좁은 화면에서는 아래 시트)을 펴고 접습니다. 카드를 누르면 펼쳐집니다

    
더보기핀 다시 읽기·쪽 이동·확대·테마·닫힌 핀·휴지통·이 도움말

    
패널 폭·시트 높이패널 왼쪽 가장자리(아래 시트는 윗가장자리) 손잡이를 끌면 바뀌고, 탭하면 단계가 돌아갑니다. [더보기] → 패널 폭 / 시트 높이에서도 고릅니다. 시트는 끝까지 내리면 접힙니다

    
설명 보기버튼을 길게 누르면 설명이 뜹니다

  
단축키

  
드래그영역을 골라 원문 위치를 찾습니다

    
⌘ Enter / Ctrl+Enter메모 칸에서 핀 저장, 편집 칸에서 수정 저장 (한글 조합 중에는 무시)

    
Esc열린 것부터 닫습니다: 도움말 → 툴팁 → 위치 다시 잡기 → 편집 취소 → 선택 취소

    
Ctrl/⌘ + 휠 · Ctrl/⌘ + = − 0PDF 위에서 확대·축소(포인터 자리 기준), 0 은 폭 맞춤. 트랙패드 핀치도 같습니다. PDF 만 커지고 패널은 그대로입니다 (입력 칸 밖에서)

    
?이 도움말 (입력 칸 밖에서)

    
Ctrl+PgUp/PgDn · Alt+1…9문서 전환(문서가 여럿일 때, 입력 칸 밖에서). 브라우저가 이 키를 먼저 가져가면 PDF 위 문서 탭을 누르세요. 문서마다 보던 자리·확대를 기억합니다

    
Ctrl/⌘ + \핀 패널(좁은 화면에서는 아래 시트)을 펴고 접습니다 (입력 칸 밖에서)

    
폭 손잡이본문과 패널 사이 막대를 끌면 패널 폭이 바뀝니다. 오른쪽 끝까지 끌면 패널이 접히고, 오른쪽 가장자리에 남는 막대를 왼쪽으로 끌거나 두 번 클릭하면 다시 펴집니다. 두 번 클릭하면 좁게 → 보통 → 넓게, 포커스한 뒤 ←/→·Home/End 로도 바뀌고 Enter 는 접고 폅니다. 폭과 접힘은 브라우저에 기억됩니다

  
용어

  

    
핀출력물의 한 자리 + 요청이나 질문 + 그 대화. 번호(#N)는 다시 쓰이지 않습니다

    
수정 요청 · 질문핀을 저장할 때 고릅니다. 질문 핀은 에이전트가 원고를 고치지 않고 스레드에 답을 단 뒤 닫습니다

    
스레드 · 답글카드 아래의 대화. 사람과 에이전트가 [답글]로 주고받고, 닫기·다시 열기·확인도 한 줄씩 남습니다

    
검토 대기에이전트가 닫은 핀은 바로 완료가 되지 않고 여기서 사람의 [확인]을 기다립니다. 작성자에게 권하지만 누구나 누를 수 있습니다. 테일넷 사람이 [완료]를 누르면 그 사람이 검토자라 바로 완료입니다

    
답글이 하는 일검토 대기·완료 핀에 사람이 단 답글은 핀을 다시 열어 에이전트에게 보냅니다(답글이 곧 고칠 점). 사람을 @태그한 답글은 그 사람과의 대화로 남고 상태는 그대로입니다. 질문 핀의 답글은 답으로 남습니다. 답글 칸 아래 한 줄이 보내면 무엇이 되는지 미리 알려 주고, 드물게 [상태 유지]로 바꿉니다. 보낸 뒤 알림의 [되돌리기]로 취소합니다

    
휴지통[삭제]한 핀이 30일 동안 머무는 곳입니다. [더보기] → 휴지통(데스크톱은 목록 아래)에서 같은 번호로 되살립니다. 30일이 지나면 저절로 지워지고, 소유자는 바로 영구 삭제할 수 있습니다

    
앵커핀을 찍을 때 떠 둔 첫·끝 문장. 원고가 고쳐지면 이것으로 새 줄 번호를 찾습니다

    
줄 이동원고 수정으로 핀 위치가 밀려 다시 맞췄다는 표시('줄 +3 이동')

    
위치 잃음첫 문장이 바뀌거나 지워져 위치를 되찾지 못함. [수정] → 위치 다시 잡기로 고칩니다

    
위치 불확실드래그한 글자가 찾은 줄 범위에 90%보다 적게 들어 있을 때 붙는 배지입니다(90% 이상이면 배지가 없습니다). 30% 미만이면 노란색. 설명에 찾은 방법(좌표·글자)과 일치율이 있습니다 — 원문 칸에서 고칠 곳이 그 줄들에 있는지 확인하세요

    
#N 범위 안 · #N과 같은 범위 · #N과 일부 겹침다른 열린 핀과 줄 범위가 겹친다는 배지. 앞의 둘은 한 번에 고치고 함께 닫는 편이 낫고, 일부 겹침은 참고만 합니다

    
작성자tailscale 로 들어온 사람은 계정 이름으로, 로컬·에이전트 요청은 '로컬/에이전트'로 기록됩니다. 기록이 생기기 전 핀은 '기록 전'

    
PDF 재빌드 vs 핀 다시 읽기앞의 것은 원고를 컴파일해 화면을 바꾸고(수십 초), 뒤의 것(구 '새로고침')은 핀 목록만 다시 읽습니다(즉시)
